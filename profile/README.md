# SelfHost Atlas

Tested self-hosting guides, honest VPS cost math, and an open dataset of install instructions that were actually run on a real, fresh server.

**Website:** <https://selfhostatlas.com> · **Methodology:** <https://selfhostatlas.com/how-we-test>

## Repositories

- [`selfhost-atlas-data`](https://github.com/selfhostatlas/selfhost-atlas-data) — open install-verification and catalog dataset (CC BY 4.0), with measured idle RAM and disk. [DOI 10.5281/zenodo.22983606](https://doi.org/10.5281/zenodo.22983606)
- [`selfhostatlas-ui`](https://github.com/selfhostatlas/selfhostatlas-ui) — UI components.
